# 安全区入口检查站 · 信号检测论（SDT）交互模拟器

## 如何运行

直接双击 `index.html` 即可，无需服务器、无需安装任何依赖。

推荐使用最新版 Chrome、Edge 或 Firefox。

## 项目简介

玩家扮演丧尸末日安全区入口的检查员。三天前，一支外出搜集物资的队伍遭遇尸群并被冲散、失去联络；从昨夜起，带伤队员陆续摸回安全区。玩家必须在有限时间内判断眼前的队友是否带有丧尸感染特征。这里的“隔离观察”指单独隔离 48 小时，不是处决；它能控制风险，但也会损失劳动力和隔离资源。

每局结束后，系统自动计算击中、漏报、虚报、正确拒绝，并用 d′、判断标准 c、ROC 曲线解释“辨别力”和“决策偏好”为什么是两个独立维度。

## 玩法

1. 在任务简报页设置辨别难度 d′、试次数量、信号先验 P(S)、安全区政策、单次限时和反馈选项。
2. 逐个判断归队队员：按 `A` 或 `←` 放行，按 `D` 或 `→` 隔离观察。
3. 每次判断都有倒计时；超时一律按放行处理。
4. 结束后查看混淆矩阵、SDT 指标、分布图、ROC 曲线和个性化解读。
5. 在理论实验室中拖动 d′、c 与先验概率，观察两率和 ROC 工作点的实时变化。

## 信号检测论说明

- **信号 S**：伤口由丧尸造成，带有组织青紫发灰、边缘溃烂、齿列印记、黑色血管纹等尸毒侵蚀特征。
- **噪音 N**：伤口由野狗咬、碎玻璃划、铁丝网剐或同伴武器误伤造成，可能同样大、深、吓人，但没有尸毒侵蚀特征。
- **击中 H**：实际是信号，判断为隔离。
- **漏报 M**：实际是信号，判断为放行。
- **虚报 FA**：实际是噪音，判断为隔离。
- **正确拒绝 CR**：实际是噪音，判断为放行。

隔离观察持续 48 小时。虚报的代价是有限的：安全区会暂时失去一名劳动力并占用一个隔离位，而不是直接处决队员。

核心公式：

```text
P(Hit) = H / (H + M)
P(FA)  = FA / (FA + CR)
d′     = z(Hit) − z(FA)
c      = −½ · [z(Hit) + z(FA)]
准确率 = (H + CR) / N
```

当任意计数格为 0 时，原始比例会变成 0 或 1，probit 会得到无穷值。因此结果页提供 **log-linear 校正**开关：每格加 0.5，每类试次总数加 1。该校正只在存在极端比例时启用。

## 代价矩阵与最优标准

游戏里的两种错误不是等价的。漏报让感染者混入安全区，虚报则损失劳动力和隔离物资。先验概率与代价共同决定理论最优判断标准：

```text
β_opt = [P(N)/P(S)] · [V(CR)−V(FA)] / [V(H)−V(M)]
c_opt = ln(β_opt) / d′
```

简报页提供三档安全区政策：

- **人道优先**：漏报 : 虚报 = 1 : 1
- **均衡**：漏报 : 虚报 = 2 : 1
- **铁腕**：漏报 : 虚报 = 6 : 1

均衡政策下，先验与代价会在 `P(S) = 1/3` 附近抵消，所以 `c_opt ≈ 0`。感染者更少时，先验通常把最优标准推向保守；漏报更昂贵时，代价把最优标准推向激进。

结果页除保留准确率外，还显示“安全区稳定度”：以 100 为基准，再累计每一次 H / M / FA / CR 的收益变化。例如均衡政策的扣分为 `−4×FA − 8×M`。这能直观说明为什么准确率把四种结果等权处理并不总适合真实决策。

## 加分功能

- 理论实验室：可拖动 d′、c 和 P(S)，实时观察分布、两率与 ROC 工作点。
- 历史战绩：使用 `localStorage` 保存最近 50 局，并在结果页显示前 10 名。
- Canvas 场景：程序化绘制不同外貌的幸存者、连续变化的伤口证据强度。
- 末日氛围：探照灯、扫描线、暗角、噪点与 Web Audio 合成音效。

## 技术说明

项目是纯前端、零依赖实现。由于需要支持 `file://` 协议直接打开，未使用 ES Module，也没有任何网络请求或外部字体、音频、图片资源。所有模块通过全局 `SDT` 命名空间按固定顺序加载。
