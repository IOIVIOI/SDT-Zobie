任务简报

末日第 1,284 天。你是 7 号安全区 入口的检查员。 三天前，一支外出搜集物资的队伍在旧城区遭遇尸群，激战中被打散、失去联络。 从昨夜起，幸存者陆续摸回安全区——每一个人身上都带着伤。

混战里没人分得清伤口是怎么来的：丧尸咬的、碎玻璃划的、队友武器擦的、从二楼摔下来磕的。 丧尸造成的伤口带有特征性的坏死表现；而野狗撕咬、铁丝网剐蹭、跌落擦伤造成的普通外伤， 在昏暗的探照灯下看起来极其相似。 你必须根据伤口的"感染特征强度"，判断归队的这个人该放行还是隔离观察。

⚠ 放走一个被咬的人，小队要出动镇压，代价高昂；冤枉一个健康的队友，你损失一个人手，还寒了所有人的心。 两种错误都要付账，只是价钱不一样——这正是信号检测论要研究的问题。

信号与噪音

信号 S（Signal）

归队队员身上的伤口，是丧尸造成的咬痕 / 抓痕。

尸毒会侵蚀伤口组织，造成坏死：组织从暗红、青紫，一路走到灰黑溃烂， 齿列印记逐渐清晰。尸毒会沿血管扩散，在伤口周围留下暗色纹路。 侵蚀越深，这些迹象越明显。

⚠ 但刚被咬不久的伤口，尸毒还没扩散，看上去可能和普通外伤没什么两样。

噪音 N（Noise）

归队队员身上的伤口来自混战中的其他原因——野狗咬的、碎玻璃划的、铁丝网剐的、同伴武器误伤的。

这些伤口本来是普通外伤。但如果伤得重——组织被压碎、撕开、缺血—— 同样会发生组织失活，发暗、发紫、边缘翻卷溃烂。 深层撕裂伤如果伤及血管，皮下也会淤出沿血管走向的暗色纹路。

⚠ 在昏暗的探照灯下，它和轻度坏死的伤口很难分辨。

关键：不要问"鲜红还是青紫"——两种伤都可能出现任何一种颜色。 你要判断的是组织坏死到了什么程度： 越接近灰黑溃烂、齿列印记越清晰、黑色血管纹越明显，就越可能是尸毒侵蚀。

核心指标

P(Hit) = H / (H + M)　击中率
P(FA) = FA / (FA + CR)　虚报率
d′ = z(Hit) − z(FA)　辨别力指数
c = −½·[ z(Hit) + z(FA) ]　判断标准
准确率 = (H + CR) / N
β_opt = [P(N)/P(S)] · [V(CR)−V(FA)] / [V(H)−V(M)]
c_opt = ln(β_opt) / d′　最优判断标准
稳定度 = 100 + 四格收益累计
